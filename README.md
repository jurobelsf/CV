# LaTeX CV

Source code for my CV, written in LaTeX.

I wanted the CV to have a visual identity that was a little different from the usual academic / corporate templates. The design is mainly inspired by the visual language around bleep techno, early electronic music releases, and 90s experimental club records.

I took some inspiration from the typography used in dubplates and record artwork, as well as the colors and minimal layouts found in some of the albums and labels I like.

The CV is kept intentionally compact since I use it mainly as a practical document for applications.

## Files

- `cv.tex` — LaTeX source of the CV.
- `cv.pdf` — Compiled version.
